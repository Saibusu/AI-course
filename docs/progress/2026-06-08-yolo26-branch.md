## 技術說明：task='detect' vs task='segment'

ADR-001 原始規定使用 segmentation variant，但目前訓練資料（merged_v3）為 **bounding box 格式**（detection labels only）。

**現階段做法**：
- 使用 `yolo26s-seg.pt` 作為 backbone（保留 seg 預訓練特徵）
- 以 `task='detect'` 訓練（僅訓練 detection head）
- 輸出模型可做 detection，seg head 不訓練

**未來改善路徑**（若時間允許）：
- TACO annotations.json 包含 COCO polygon mask → 可轉換為 seg 格式
- 修改 `prepare_taco.py` 輸出 polygon 標註
- 改 `task='segment'` 完整訓練 seg head

### 第一次嘗試（失敗）

| 問題 | 說明 |
|------|------|
| PIL ImportError | `pip install -U` 升級 Pillow 後需 Runtime Restart |
| RuntimeError（seg loss） | `yolo26s-seg.pt` + `task='detect'` → tensor size mismatch |
| RuntimeError（seg loss 再次） | `yolo26s-seg.pt` 預設 `task='segment'` → 需要 polygon mask，我們只有 bbox |

**根本原因**：`yolo26s-seg.pt` segmentation 訓練需要 polygon mask 標註，merged_v3 為 bounding box 格式。

- 仍為 YOLO26 世代，符合 ADR-001 核心要求
- 與 bounding box 標註相容，不需 polygon mask
- 已 commit `fix(yolo26): switch to yolo26s.pt` 並推上 `feature/yolo26`
