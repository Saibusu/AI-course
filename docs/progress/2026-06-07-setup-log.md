# 開發操作紀錄 — 2026-06-07

## 1. Jetson 環境建置

### 操作方式
筆電透過 SSH 連線至 Jetson（yahboom 板）進行操作。

### 步驟

**Clone 專案**
```bash
git clone https://github.com/Saibusu/AI-course.git
cd AI-course
```

**安裝 Python 依賴**
```bash
pip install -r requirements.txt
```

### 遭遇問題與解決

| 問題 | 原因 | 解法 |
|------|------|------|
| `opencv-python-headless 4.13` 與 `numpy<2` 衝突 | opencv 4.9+ 要求 numpy≥2，Jetson torch 要求 numpy<2 | 降版為 `opencv-python-headless>=4.8.0,<4.9.0` |
| numpy 版本衝突循環 | pip 自動升級 numpy 至 2.2.6 | 固定 `numpy>=1.24.0,<2.0.0` in requirements.txt |
| `Jetson.GPIO` 安裝提示 | 已預裝於系統 `/usr/lib/python3/dist-packages`（v2.1.7） | 無需額外安裝 |

### 最終環境版本

| 套件 | 版本 |
|------|------|
| Python | 3.10 |
| ultralytics | 8.3.59 |
| opencv-python-headless | 4.8.1 |
| numpy | 1.26.4 |
| Jetson.GPIO | 2.1.7（系統預裝） |

## 2. Colab 訓練環境建置

### 環境
- Google Colab（免費方案）
- GPU：Tesla T4
- 連線方式：筆電瀏覽器開啟 Colab，從 GitHub 開啟 `train_colab.ipynb`

### 資料集

**來源**：Kaggle — `asdasdasasdas/garbage-classification`（TrashNet 格式）
**下載方式**：Kaggle API Token（環境變數 `KAGGLE_TOKEN`，不納入版本控制）

**實際資料夾結構**（與原始 TrashNet 不同，多一層子目錄）：
```
data/TrashNet/
  garbage classification/
    Garbage classification/
      glass/     (501 張)
      trash/     (137 張)
      metal/     (410 張)
      paper/     (594 張)
      cardboard/ (403 張)
      plastic/   (482 張)
```

**執行轉換指令**（需指定正確路徑）：
```bash
python data/prepare_trashnet.py \
    --trashnet-dir "data/TrashNet/garbage classification/Garbage classification" \
    --output-dir data/trashnet_yolo
```
