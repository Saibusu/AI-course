### Cell 8 SameFileError 修正

錯誤原因：glob 搜到根目錄的舊 `best.pt`，`shutil.copy('best.pt','best.pt')` 自我複製。

修正版（直接在 Colab 執行）：

```python
import glob, shutil, os
from google.colab import files

pts = glob.glob('**/best.pt', recursive=True)
src = next((p for p in pts if 'waste_sorter_v2' in p), None)
if src is None:
    src = next(p for p in pts if p != 'best.pt')

print(f'使用模型：{src}')
shutil.copy(src, 'best_v2.pt')
print(f'Model size: {os.path.getsize("best_v2.pt")/1e6:.1f} MB')
files.download('best_v2.pt')
```
